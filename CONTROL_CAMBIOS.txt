RESUMEN EJECUTIVO
================================================================================

Este proyecto implementa un sistema de chat cliente-servidor con cifrado
híbrido (RSA + AES) de grado empresarial, migrado a arquitectura asíncrona
para máxima escalabilidad y rendimiento. El sistema utiliza RSA-2048 para
intercambio seguro de claves y AES-256-GCM con HMAC-SHA256 para cifrado rápido
de mensajes. La versión 4.0 agrega validación obligatoria de SHA256 en cada
mensaje, descartando automáticamente mensajes con integridad comprometida.

MEJORAS DE SEGURIDAD IMPLEMENTADAS
================================================================================

1. CIFRADO HÍBRIDO
   - RSA-2048: Cifrado asimétrico para intercambio seguro de claves AES
   - AES-256-GCM: Cifrado simétrico rápido para mensajes
   - Padding OAEP: Con SHA256 para RSA
   - Claves RSA generadas dinámicamente por conexión

2. INTERCAMBIO DE CLAVES
   - Intercambio automático de claves públicas RSA
   - Clave AES cifrada con RSA antes de transmitirse
   - Sin contraseñas compartidas requeridas
   - Cada conexión establece su propia clave AES

3. VERIFICACIÓN DE INTEGRIDAD
   - HMAC-SHA256: Verificación de integridad del payload cifrado
   - SHA256 Hash: Verificación adicional del mensaje descifrado
   - Logs incluyen hash SHA256 para auditoría

4. PROTOCOLO DE CIFRADO
   Fase 1 - Intercambio de claves:
   - Cliente y servidor intercambian claves públicas RSA
   - Cliente genera clave AES y la cifra con RSA del servidor
   - Servidor descifra clave AES con su clave privada RSA
   
   Fase 2 - Cifrado de mensajes con validación SHA256 (v4.0):
   Estructura: [4 bytes: longitud] + [32 bytes: Hash SHA256] + [12 bytes: IV] + 
               [16 bytes: Tag GCM] + [32 bytes: HMAC] + [ciphertext]
   
   Validación:
   - Cliente calcula hash SHA256 del mensaje original
   - Cliente envía hash SHA256 junto con mensaje cifrado
   - Servidor extrae hash SHA256 recibido
   - Servidor descifra mensaje y calcula hash SHA256
   - Servidor compara hashes: si coinciden acepta, si no descarta
